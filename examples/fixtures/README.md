# Example fixtures

`red-square.png` is a generated 32 by 32 red RGB test image.
`red-square.mp4` is a one-second red H.264 video generated with FFmpeg.
`refund_policy.md` is fictional example text.
`sample.pdf` is the W3C PDF test fixture whose visible text is "Dummy PDF file",
from [W3C WAI test resources](https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf).

Provider examples read these files from a repository checkout. Copy the files
into your application when adapting an example. They contain no personal data.
